# n8n Node Builder - Frontend Visual

Frontend visual para crear y editar nodos de n8n sin tocar código TypeScript.

## 🚀 Iniciar

```bash
cd node-builder
node server.js
```

Abre tu navegador en: **http://localhost:3000**

## ✨ Características

- ✅ Lista todos los nodos existentes en tu proyecto
- ✅ Crea nuevos nodos visualmente
- ✅ Edita nodos existentes
- ✅ Agrega propiedades (campos) fácilmente
- ✅ Define operaciones HTTP (GET, POST, etc.)
- ✅ Configura autenticación
- ✅ Preview del código TypeScript en tiempo real
- ✅ Guarda y genera archivos automáticamente

## 📝 Cómo usar

1. **Crear un nodo nuevo**: Click en "+ Nuevo Nodo"
2. **Completar información básica**: Nombre, descripción, categoría
3. **Agregar propiedades**: Los campos que verá el usuario
4. **Agregar operaciones** (opcional): Para nodos tipo API
5. **Guardar**: Genera automáticamente los archivos .ts y .json
